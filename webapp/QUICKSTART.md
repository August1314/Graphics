# 快速开始指南

## 🚀 启动应用

### 方法 1：使用启动脚本（推荐）
```bash
cd webapp
./start.sh
```

### 方法 2：使用 Python 内置服务器
```bash
cd webapp
python3 -m http.server 8000
```

### 方法 3：使用 Node.js http-server
```bash
cd webapp
npx http-server -p 8000
```

然后在浏览器中打开：`http://localhost:8000`

---

## ✨ 主要功能

### 🎨 绘图工具
- **选择工具**：点击选择图形，拖动移动
- **点工具**：点击创建点
- **线工具**：点击起点，再点击终点
- **矩形工具**：点击起点，拖动到终点
- **圆形工具**：点击圆心，拖动设置半径
- **多边形工具**：点击添加顶点，双击完成
- **画笔工具**：按住鼠标拖动绘制
- **橡皮擦工具**：点击或拖动擦除图形

### 🎨 样式控制
- **描边颜色**：点击颜色选择器设置线条颜色
- **填充颜色**：设置图形填充颜色
- **线宽**：使用滑块调整线条粗细

### ↩️ 操作控制
- **撤销**：Ctrl+Z 或点击撤销按钮
- **重做**：Ctrl+Y 或点击重做按钮
- **清空**：清除画布上所有图形

### 💾 导出功能
- **导出 PNG**：将画布导出为图片
- **保存 JSON**：保存为 JSON 格式（可重新加载）
- **加载 JSON**：从 JSON 文件加载作品

### 🌓 主题切换
- 点击右上角的主题切换按钮
- 支持浅色和深色两种主题

---

## 📱 响应式支持

应用完全支持响应式设计：
- **桌面端**（≥ 1024px）：完整功能
- **平板端**（≥ 768px）：优化布局
- **移动端**（< 768px）：底部导航栏

---

## 🎯 快捷键

- `Ctrl+Z`：撤销
- `Ctrl+Y`：重做
- `Ctrl+S`：保存（导出 JSON）
- `Esc`：取消当前操作

## 🐛 故障排除

### 问题：页面无法加载
- 确保使用 HTTP 服务器（不要直接打开 HTML 文件）
- 检查浏览器控制台是否有错误

### 问题：Canvas 不显示
- 检查浏览器是否支持 Canvas API
- 尝试刷新页面

### 问题：工具不工作
- 确保已选择工具（工具按钮应该高亮）
- 检查浏览器控制台是否有 JavaScript 错误
