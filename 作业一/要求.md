## 项目名称
二维图形绘图系统（Graphics Assignment 1）

## 文档目的
本文件用于指导“二维图形绘图系统”的规划、设计与实现，明确范围、需求、架构、数据与接口、测试与交付标准，确保团队在有限时间内交付可用、可靠并具备扩展性的作业项目。

## 背景与目标
- 了解二维图形的基本构成与属性，掌握通过编程进行图形创建、编辑、存储与加载的流程。
- 熟悉常用图形编程库/框架（如 HTML5 Canvas/WebGL、Qt、JavaFX、WPF、SDL、OpenCV 等）的使用。
- 交付一个具备完整图形化交互的应用，支持基本绘制、编辑、属性设置与文件持久化。

## 项目范围
- 涵盖：二维图形绘制与编辑、基本视图交互（拖动/缩放/选择）、样式属性管理、文件读写、基础撤销/重做（可选）、吸附与对齐（可选）。
- 不涵盖：复杂 DCC（如 Illustrator 级别）完整功能、高精度排版/印刷特性、超大规模协同、云端实时多用户编辑。

## 术语定义
- 图元：点、线段、矩形、圆/椭圆、多边形等基本二维形状。
- 画布：绘制与展示图元的区域，可缩放与平移。
- 属性：颜色、线宽、线型、填充颜色/纹理、透明度等。
- 场景/文档：当前画布上图元及其层次与属性的集合。

## 用户画像
- 初学者/学生：完成课程作业，验证图形学/人机交互基本概念。
- 助教/教师：验证功能完整性与稳定性，进行评分与演示。

## 功能需求
### 必选功能
1) 图形绘制
   - 支持图元：点、直线、矩形、圆（可扩展为椭圆）、多边形（闭合）。
   - 交互方式：通过工具栏选择图元类型，在画布上点击或拖拽完成创建。

2) 图形编辑
   - 选择/多选、移动（拖动）。
   - 缩放：整画布缩放（滚轮/手势）；可选支持选中图元的缩放句柄。
   - 删除与复制：删除选中图元、复制/粘贴图元。

3) 属性设置
   - 线条：颜色（RGB/HEX）、线宽、线型（实线/虚线）。
   - 填充：填充颜色、可选支持无填充与透明度。

4) 文件存储与加载
   - 支持保存当前场景为本地文件（推荐 JSON/自定义文本格式）。
   - 支持从文件恢复场景（加载）。

5) 图形化界面
   - 主画布区域 + 工具栏（图元工具、选择工具）+ 属性面板 + 菜单/状态栏。
   - 视图交互：画布平移（中键/空格+拖拽）、缩放（滚轮）。

### 可选/加分功能（任意选择实现）
- 撤销/重做（基于命令栈）。
- 网格与吸附（到网格/顶点/边）。
- 图层管理与锁定/隐藏。
- 导出为 SVG/PNG（若技术路线支持）。
- 约束编辑（保持矩形正方、圆形半径统一等）。
- 简单三维扩展（如将二维图形拉伸为 3D 体，或 3D 视角浏览）。
- 自定义纹理填充。
- 多语言界面（中/英）。

## 非功能性需求
- 可用性：核心操作路径不超过 3 步即可完成（选择工具→绘制→属性调整→保存）。
- 性能：100 个普通图元下交互流畅（> 30 FPS）。
- 可靠性：异常操作不崩溃，文件读写失败需提示且不丢失现有场景。
- 可维护性：模块化设计，清晰分层；关键模块具备单元测试。
- 可移植性：优先选择跨平台技术；或明确运行环境（Windows/macOS/Linux/浏览器）。

## 典型用例
1) 绘制矩形并设置为红色填充、3px 绿色描边，然后保存为文件。
2) 导入已有场景，选择一个圆形，将其拖拽到新位置并缩放画布观察细节。
3) 使用多边形工具绘制多边形，修改透明度与线型，导出图像（可选）。

## 交互与界面设计（示意）
- 工具栏：选择、点、直线、矩形、圆、多边形、删除、撤销/重做（可选）。
- 属性面板：填充颜色、描边颜色、线宽、线型、透明度。
- 画布：支持滚轮缩放、拖拽平移；显示坐标/缩放比例（状态栏）。
- 快捷键（建议）：
  - V：选择工具；
  - P/L/R/C/G：点/线/矩形/圆/多边形工具；
  - Delete：删除；Ctrl/Command+Z/Y：撤销/重做；Space+拖拽：平移；Ctrl/Command+S：保存。

## 系统架构设计
### 分层
- 表现层（UI）：工具栏、属性面板、画布视图与交互。
- 业务层（Domain）：图元模型、选择与编辑、命令与撤销（可选）。
- 数据层（Persistence）：场景序列化/反序列化、文件 IO。

### 模块与职责
- Shape 模块：定义点/线/矩形/圆/多边形接口与实现，统一绘制与命中测试 API。
- Canvas/Renderer 模块：负责坐标变换、网格与标尺（可选）、批量绘制优化。
- Selection/Tool 模块：工具状态机与事件分发（按下/移动/释放）。
- Property 模块：属性绑定、即时预览与应用。
- Storage 模块：导入导出（JSON/SVG/PNG 视技术而定）。

## 数据模型（建议）
- Document
  - id, name, createdAt, updatedAt
  - canvas: width, height, zoom, pan
  - shapes: Shape[]
- Shape（多态）
  - common: id, type, strokeColor, strokeWidth, strokeDash, fillColor, opacity
  - 点：x, y
  - 线：x1, y1, x2, y2
  - 矩形：x, y, width, height, cornerRadius?（可选）
  - 圆/椭圆：cx, cy, r（或 rx, ry）
  - 多边形：points: [x, y][]

## 文件格式（示例 JSON）
```json
{
  "name": "scene-1",
  "canvas": { "width": 1200, "height": 800, "zoom": 1, "pan": {"x": 0, "y": 0} },
  "shapes": [
    { "id": "s1", "type": "rect", "x": 100, "y": 120, "width": 200, "height": 100, "strokeColor": "#00AA00", "strokeWidth": 3, "fillColor": "#FF0000" }
  ]
}
```

## 技术选型（建议）
- 桌面端：Qt/C++, WPF/.NET, JavaFX/Java。
- Web 端：TypeScript + Canvas/SVG/WebGL + 前端框架（React/Vue/Svelte，三选一）。
- 首选具备个人熟悉度且可快速交付的技术栈；允许调用现有库。

## 关键接口（示意）
- Shape 接口：`draw(ctx)`, `hitTest(point)`, `toJSON()`, `fromJSON(data)`。
- Tool 接口：`onPointerDown`, `onPointerMove`, `onPointerUp`, `cancel`。
- Storage：`save(document, filePath)`, `load(filePath): document`。

## 状态与事件
- 工具状态机：空闲→绘制中→完成；选择→拖拽→释放。
- 画布状态：缩放比例、平移偏移；窗口尺寸变化时的自适应。
- 事件模型：指针/鼠标、键盘快捷键、窗口与设备像素比变化。

## 错误处理与提示
- 文件读写失败：提示原因与恢复建议（如权限/格式错误）。
- 无效操作：例如未选择图元时的删除操作，给予非打断式提示。
- 崩溃保护（可选）：自动定时保存到临时文件。

## 性能与优化建议
- 分层绘制与脏矩形重绘；
- 命中测试优先使用包围盒，必要时再做精确几何判断；
- 合理使用离屏缓存（可选）。

## 安全与权限
- 桌面应用：文件系统读写权限最小化；
- Web 应用：仅在用户同意时使用文件系统访问 API；不上传用户数据至服务器。

## 国际化与可访问性（可选）
- 文案多语言资源文件；
- 高对比度主题与键盘操作路径。

## 测试计划
- 单元测试：数据模型、序列化/反序列化、几何计算（如命中测试）。
- 集成测试：绘制-编辑-保存-加载的主流程回归。
- 手工测试：多平台/浏览器兼容性、性能与交互细节。

## 里程碑与进度
- M1（第 1 周）：技术选型与脚手架、数据模型草案、画布基础与坐标变换。
- M2（第 2 周）：点/线/矩形/圆/多边形绘制与选择/拖动；属性面板联动。
- M3（第 3 周）：文件读写；视图缩放/平移；稳定性与性能优化。
- M4（第 4 周）：加分功能若干、测试与文档完善、演示准备。

## 验收标准
- 功能：必选功能全部可用；核心用例可在 5 分钟内演示完成。
- 质量：无阻断性崩溃与数据丢失；错误提示清晰。
- 文档：包含使用手册（README）与示例文件；代码注释关键模块。
- 亮点：至少 1 项具有创意或工程价值的扩展功能。

## 风险与缓解
- 技术栈不熟导致延期 → 选择熟悉技术/缩小可选功能范围。
- 文件格式兼容性问题 → 先定义最小可用 JSON 模式并固定版本。
- 交互细节复杂 → 优先实现“选择-拖动-保存-加载”的闭环，分阶段迭代。
