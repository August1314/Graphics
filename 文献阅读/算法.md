# LLM4SVG算法框架

根据论文内容，LLM4SVG是一个使大型语言模型(LLMs)能够理解和生成复杂矢量图形的框架。虽然论文中没有明确列出算法伪代码，但可以通过其关键组件和训练流程进行重构。

## 核心公式

### 1. SVG语义标记初始化

对于SVG语义标记$s$，其嵌入通过语义平均初始化：

$$E(s) = \frac{1}{n}\sum_{j=1}^{n}W_{emb} \cdot w_j$$

其中：
- $E(s)$表示标记$s$的嵌入向量
- $n$是标记$s$描述文本的编码长度
- $W_{emb}$是嵌入层参数
- $w_j$表示描述$s$的第$j$个标记

### 2. 模型训练目标函数

对于长度为$L$的序列，模型计算目标回答$X_a$的条件概率：

$$p(X_a|X_v, X_{inst}) = \prod_{i=1}^{L} p_{\varepsilon}(x_i|X_v, X_{inst}, X_a, \hat{x}_{i-1})$$

其中：
- $X_v$是输入SVG
- $X_{inst}$是指令数据
- $\hat{x}_{i-1} := (x_{i-1}, \cdots, x_1)$表示前$i-1$个已预测的标记
- $\varepsilon$是模型可训练参数

## LLM4SVG构建流程

\begin{algorithm}
\caption{LLM4SVG框架构建流程}
\label{alg:llm4svg}
\begin{algorithmic}[1]
\REQUIRE 预训练LLM $f_{\omega}$，SVG数据集 $\mathcal{D}_{svg}$，图像编码器(可选)
\ENSURE 训练好的LLM4SVG模型
\STATE \textbf{// 阶段1: SVG数据预处理和语义标记定义}
\STATE 收集并标准化250,000+高质量SVG文件
\STATE 定义55个SVG语义标记集$\mathcal{S} = \{s_1, s_2, ..., s_{55}\}$，包括:
\begin{itemize}
    \item 15个标签标记(如<path>, <g>, <svg>等)
    \item 30个属性标记(如<fill>, <stroke>, <d>等)
    \item 10个路径命令标记(如<moveto>, <lineto>, <smooth\_curveto>等)
\end{itemize}
\STATE 为每个SVG生成栅格化图像$X_{img} \leftarrow \text{Rasterize}(X_v)$
\STATE 用BLIP模型生成简短描述$p_{short} \leftarrow \text{BLIP}(X_{img})$
\STATE 用GPT-4生成详细描述$p_{long} \leftarrow \text{GPT4}(X_{img}, p_{short})$
\STATE 构建5种指令模板(见表1)，生成580k训练样本的SVGX-SFT数据集

\STATE \textbf{// 阶段2: 模型架构设计}
\STATE 选择基础LLM(如GPT-2, Phi-2, Falcon等)
\STATE 扩展标记器词汇表:$|V_{new}| = |V_{orig}| + 55$
\STATE 使用公式(1)初始化SVG语义标记的嵌入

\STATE \textbf{// 阶段3: 两阶段训练}
\STATE \textit{// 阶段3.1: 特征对齐预训练}
\STATE 冻结视觉编码器和LLM参数，仅训练嵌入层$W_{emb}$
\FOR{每个训练样本$(X_v, X_{inst}, X_a)$}
    \STATE 计算损失$\mathcal{L} = -\log p(X_a|X_v, X_{inst})$，使用公式(2)
    \STATE 更新$W_{emb}$参数
\ENDFOR

\STATE \textit{// 阶段3.2: 端到端微调}
\STATE 解冻模型参数，可选择:
\begin{itemize}
    \item \textit{参数高效微调}: 仅微调低秩适配器(LoRA/QLoRA)
    \item \textit{全参数微调}: 微调所有模型参数$\varepsilon = \{W_{emb}, \omega\}$
\end{itemize}
\FOR{每个训练批次}
    \STATE 采样对话数据$(X_v^1, X_{inst}^1, X_a^1), ..., (X_v^T, X_{inst}^T, X_a^T)$
    \STATE 优化损失$\mathcal{L}_{total} = \sum_{t=1}^T -\log p(X_a^t|X_v^t, X_{inst}^t)$
\ENDFOR

\STATE \textbf{return} 训练好的LLM4SVG模型
\end{algorithmic}
\end{algorithm}

## 推理过程

\begin{algorithm}
\caption{LLM4SVG推理流程}
\label{alg:inference}
\begin{algorithmic}[1]
\REQUIRE 训练好的LLM4SVG模型，输入$X_{input}$
\ENSURE 生成的输出$Y_{output}$
\IF{任务类型 = "SVG理解"}
    \STATE 输入SVG代码$X_v$和理解指令$X_{inst}$
    \STATE $Y_{output} \leftarrow f_{\varepsilon}(X_v, X_{inst})$  // 生成SVG的语义描述
    \STATE \textbf{return} 语义描述文本
\ELSIF{任务类型 = "SVG生成"}
    \STATE 输入文本提示$X_{prompt}$和可选的参考图像$X_{img}$
    \STATE $Y_{output} \leftarrow f_{\varepsilon}(X_{prompt}, X_{img})$  // 生成SVG代码
    \STATE 将语义标记转换为标准SVG代码
    \STATE \textbf{return} 生成的SVG源代码
\ENDIF
\end{algorithmic}
\end{algorithm}

## 关键模块详解

1. **SVG语义标记模块**：将SVG元素转换为结构化表示，避免LLM将SVG标签当作普通文本处理

2. **模块化架构**：
   - 语义初始化器：将SVG转换为语义标记序列
   - 标记嵌入器(Token Embedder)：将语义标记映射到嵌入空间
   - 大型语言模型核心：处理序列信息和生成响应
   - 渲染模块(可选)：将生成的SVG代码转换为栅格图像，提供视觉反馈

3. **训练策略**：
   - 两阶段训练：先对齐特征，再端到端微调
   - 支持参数高效微调(LoRA/QLoRA)和全参数微调
   - 融合理解任务和生成任务的多任务学习

这一框架有效解决了LLM在SVG理解和生成中的关键挑战，包括语义模糊性、数值精度问题和渲染顺序理解。
