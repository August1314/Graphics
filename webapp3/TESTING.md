# 集成测试记录（手动验收）

以下测试均在 `webapp3/draw.html` 页面完成，浏览器为 Chrome 119，操作系统 Windows 10。

## 1. Bézier 曲线
1. 在工具栏选择 `♾️ Bézier`。
2. 依次点击画布添加 4 个控制点，双击收尾；曲线应实时显示，控制多边形为蓝色虚线。
3. 选择工具框选曲线，拖动控制点，曲线应随之更新。
4. 按 `r` / `R` 观察曲线围绕中心旋转；按 `[` / `]` 缩放。

## 2. B 样条曲线
1. 选择 `🌀 B 样条` 工具，绘制多控制点曲线。
2. 切换到选择工具，拖拽控制点验证逼近效果。
3. 使用 `r` / `[` 快捷键测试整体旋转/缩放。

## 3. Bézier 曲面
1. 选择 `🧊 曲面` 工具，在画布上拖出一个长方形，生成 4×4 控制网格。
2. 拖动任意控制点，曲面网格应实时更新。
3. 双击曲面，显示模式在“网格线”与“填充”之间切换。
4. 选中曲面后按 `r` / `[` / `]`，验证网格及填充都会整体旋转/缩放。

## 4. 光栅化开关
1. 勾选/取消工具栏中的“光栅化”复选框，观察曲线/曲面在像素级渲染与 Canvas 渲染之间切换。

## 5. 撤销/重做
1. 任意绘制曲线或曲面。
2. 按 `Ctrl+Z`，图形应被撤销；再按 `Ctrl+Shift+Z` 或 `Ctrl+Y`，图形恢复。

## 6. 导出 PNG
1. 在画布存在多个曲线/曲面时，点击“导出 PNG”，应获得包含所有图形的截图文件。

## 7. JSON 保存/加载（可选）
1. 点击“保存 JSON”生成数据文件。
2. 将文件内容通过 `Document.load`（在控制台调用或扩展 UI）重新导入，确认图形和控制点还原。

> 若需自动化，请参考 `scripts` 目录中各模块的 API，自行编写 E2E 脚本或录制测试视频。
