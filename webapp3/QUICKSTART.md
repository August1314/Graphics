## 快速上手（webapp3）

本项目是二维图形绘图系统的 Web 前端实现（React 版本），支持多种图形、曲线/曲面以及光栅化算法效果对比。

### 1. 环境要求

- Node.js 16+ 和 npm/yarn
- 现代浏览器（Chrome、Firefox、Safari、Edge）

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发服务器

**Linux/macOS：**

方式一：使用启动脚本（推荐）
```bash
chmod +x start.sh
./start.sh
```

方式二：使用 npm 命令
```bash
npm run dev
# 或
npm start
```

**Windows：**

方式一：使用批处理文件（推荐）
```cmd
# 首次使用需要先安装依赖
setup_env.bat

# 然后启动开发服务器
run_server.bat
```

方式二：使用 npm 命令
```cmd
npm install
npm run dev
```

开发服务器将在 `http://localhost:5173` 启动，浏览器会自动打开。

### 4. 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist/` 目录。

### 5. 预览生产构建

```bash
npm run preview
```

### 6. 基本操作

- **工具栏**：顶部工具栏选择绘图工具（选择、点、线、矩形、圆形、多边形、画笔等），工具栏采用两行布局，支持响应式设计
- **绘制**：在画布上点击/拖拽完成绘制
- **选择和移动**：使用选择工具点击图形，然后拖动移动图形
- **编辑图形**：
  - **点击控制点**：在选择工具下点击曲线/曲面的控制点，自动切换到对应工具并开始编辑
  - **双击图形**：双击支持编辑的图形（Bézier曲线、B样条曲线、曲面），自动切换到对应工具进入编辑模式
  - 切换后可以直接拖动控制点调整形状
- **修改样式**：选中图形后，通过工具栏调整颜色和线宽（无需切换工具）
- **视图**：通过"网格"和"光栅化"开关观察网格和像素级渲染效果
- **教程**：点击右下角"教程"按钮查看交互式引导说明

### 7. 快捷键

- `1`～`9`、`B`/`S`/`M`：切换不同工具
- `Ctrl/Cmd + Z`：撤销
- `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y`：重做
- `Ctrl/Cmd + E`：导出 PNG
- `Delete/Backspace`：删除选中图形
- `Ctrl/Cmd + 0 / + / -`：重置、放大、缩小视图
- `R/r`、`[`、`]`：旋转/缩放选中曲线和曲面
- `Esc`：取消当前操作

### 8. 曲线与曲面

- **Bézier 曲线 / B 样条曲线**：
  - 使用对应工具依次点击添加控制点，双击结束
  - B 样条曲线在绘制过程中会实时显示控制点和连接线
  - 使用选择工具点击控制点会自动切换到对应工具并开始编辑
  - 双击曲线图形也会自动切换到对应工具进入编辑模式
- **Bézier 曲面**：
  - 使用曲面工具拖出一个矩形自动生成 4×4 控制网格
  - 使用精确点击检测，只有点击控制点或网格线附近才会被选中
  - 点击控制点或双击曲面会自动切换到曲面工具进行编辑
  - 双击可在"网格线"与"曲面填充"两种渲染模式之间切换

详细测试步骤参见 `TESTING.md`。
