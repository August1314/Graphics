## 1. 布局结构

- **整体网格**
  - Body 背景：浅色渐变（如 `linear-gradient(135deg, #f8fbff 0%, #eef2f8 100%)`）。
  - 主容器 `display: grid; grid-template-columns: 70% 30%; grid-template-rows: auto 1fr; gap: 24px;`
  - 左侧 70%：画布区；右侧 30%：参数/说明面板（Tabs）。

- **画布卡片**
  - 使用半透明玻璃卡片：`background: rgba(255,255,255,0.6); backdrop-filter: blur(16px); border-radius: 24px; box-shadow`.
  - Canvas 置于卡片内部，周围留 16px padding，顶部放当前模式徽章和快捷状态。
  - 左侧叠加一个窄竖工具栏（浮动在卡片内侧，圆角 + 玻璃质感），仅展示图标。

- **右侧分屏面板**
  - 同样使用玻璃卡片，分成 Tabs：
    1. **工具 & 样式**：颜色选择、线宽、透明度、光栅化开关。
    2. **曲线/曲面参数**：控制点列表（表格/卡片）、步数滑块、模式切换、变换按钮。
    3. **日志/测试**：显示最近操作、测试提示，放可点击的 `TESTING` 链接。
  - Tabs 头部使用 pill-style 按钮，选中态强调色 #2563eb。

## 2. 视觉语言

- **颜色**
  - 主色：`#2563eb`，辅助色 `#5b5fea`、`#7c3aed`。
  - 文本：深灰 `#1f2933`，次级 `#4b5563`。
  - 控制点/网格用柔和蓝（`rgba(59,130,246,0.6)`）+ 微亮点。

- **字体 & 图标**
  - 字体：`"Inter", "HarmonyOS Sans", sans-serif`。
  - 图标：保持 emoji 或替换为 SVG（可用 `tabler-icons` 或 `phosphor-icons`）。

- **动画与阴影**
  - 控件 hover：微弱升高 + 模糊背景更亮。
  - 工具切换：小型 scale 动画 + 背景模糊加深。
  - 控制点选中：从白色变为渐变蓝，添加轻微发光。

## 3.交互细节

- **工具栏**
  - 竖直布局，鼠标 hover 显示 tooltip（含快捷键）。
  - 当前工具图标加亮 + 背景动画（如 4px 光圈）。

- **模式徽章**
  - 位于画布卡片顶部：显示“Bézier 曲面 / 网格模式”文字 + mini icon。
  - 当切换模式时，徽章背景做淡入/淡出。

- **右侧参数面板**
  - Tab2 中的控制点列表：显示 `#1 (120, 200)`，点击时在 Canvas 上 flash。
  - 步数滑块 +数值：`<input type="range">` 搭配 `<input type="number">`。
  - 变换按钮放在 Tab2，保留 icon（⟲ ⟳ ➖ ➕），增加 tooltip。

- **帮助提示**
  - Tab3 提供 “快速测试流程” 卡片（套用 `TESTING.md` 的要点），点击可以展开详细步骤。

## 4. 实施步骤建议

1. **样式结构**：在 `styles` 目录新增 `modern.css` 或扩展 `layout.css`，引入 CSS 变量（颜色、模糊值、阴影）。
2. **HTML 架构调整**：重构 `draw.html`：
   - 外层 `main` 用 grid 将 Canvas 卡片与右侧面板分离。
   - 工具栏改为独立 `<aside>` 放在 Canvas 容器内。
   - 右侧面板写出 Tabs 框架（HTML + JS 控制切换）。
3. **JS 同步**：更新 `draw.html` 中的 DOM 查询逻辑，确保工具按钮、颜色控制、参数面板对应新的元素结构；可把面板逻辑拆成模块化函数。
4. **控制点列表/参数绑定**：在选择曲线/曲面时更新右侧 Tab2 的表格/输入域，支持点击聚焦控制点。
5. **调优与动画**：最后加上 transitions（`transition: all 0.2s ease-out;`）、hover/active 状态、徽章动态等。

## 5. 开发计划（执行顺序）

1. **阶段一：结构重构**
   - 在 `draw.html` 中搭建新的 `app-shell` 网格：左侧画布卡片 + 右侧面板。
   - 将现有工具按钮移入左侧竖直工具栏，保持 `tool-btn` 结构。
   - 构建右侧 Tabs 框架，并将颜色/算法/变换控件放入对应 Tab。
2. **阶段二：样式落地**
   - 新增 `styles/modern.css`，实现背景渐变、玻璃卡片、工具栏样式、面板 Tabs。
   - 引入 CSS 变量和基础动画，确保响应式（至少 1200px 下布局稳定）。
3. **阶段三：脚本联动**
   - 在 `draw.html` 脚本中添加 Tab 切换逻辑、模式徽章更新。
   - 调整工具切换、快捷键函数，确保引用的新 DOM 结构（如 `transform-section`）状态同步。
4. **阶段四：参数与帮助内容**
   - Tab2 增加控制点列表/步数滑块钩子（后续可动态填充）。
   - Tab3 引入测试流程卡片，链接至 `TESTING.md`。
5. **阶段五：细节优化**
   - 补充 hover/active 动画、光影、控制点高亮效果。
   - 预留 Hook 供后续“控制点列表 -> Canvas 聚焦”联动。
